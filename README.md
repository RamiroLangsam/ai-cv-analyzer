# AI CV Analyzer

AI CV Analyzer es una aplicación web desarrollada en Python que analiza la compatibilidad entre un CV y una oferta laboral utilizando técnicas de procesamiento de lenguaje natural.

## Funcionalidades

- Compara un CV con una oferta laboral.
- Calcula similitud de texto.
- Detecta habilidades técnicas.
- Muestra habilidades coincidentes.
- Identifica habilidades faltantes.
- Genera un puntaje general de compatibilidad.

## Tecnologías utilizadas

- Python
- Streamlit
- Scikit-learn
- NLP
- TF-IDF
- Cosine Similarity
